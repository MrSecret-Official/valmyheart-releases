# MyMochi · versiones

Aquí solo se publican las versiones firmadas (APK) de la app MyMochi para Android.
El código fuente es privado.

## Cómo instalar o actualizar
1. Abre la última versión en **Releases**.
2. Descarga el archivo `.apk` desde el teléfono.
3. Ábrelo y acepta instalar desde esta fuente si Android lo pide.

La app avisa sola cuando hay una versión nueva (se puede desactivar en Ajustes › Actualizaciones).
Todas las versiones están firmadas con la misma clave, así que se actualizan sin perder datos.
